# ResNet-18: Feature Map Flow

When an image passes through a convolutional network, each layer transforms
its input into a new set of **feature maps** — 2-D grids of activations, one
per channel. Early layers respond to low-level patterns (edges, textures);
deeper layers capture increasingly abstract, semantic features.

The visualization below shows this transformation pipeline for ResNet-18.
Pick an input pattern on the left, then read the columns left to right:

- **Stem** — a single 7×7 conv, batch-norm, ReLU, and max-pool that
  halves spatial resolution twice (224 → 112 → 56) while expanding from 3
  to 64 channels.
- **Layers 1–4** — each layer contains two *BasicBlock* residual units.
  Layers 2–4 halve spatial resolution and double the channel count at
  their first block.
- **Classifier** — global average pooling collapses each channel to a
  single number, and a fully-connected layer maps 512 features to 1000
  ImageNet class logits.

Notice how the thumbnails grow blockier as you move right — that's the spatial
resolution shrinking from 224×224 all the way down to 7×7. Meanwhile the
*number* of channels explodes (3 → 64 → 128 → 256 → 512), so the network
trades spatial detail for richer feature representations. That trade-off is
the core design principle behind virtually every modern image classifier.
