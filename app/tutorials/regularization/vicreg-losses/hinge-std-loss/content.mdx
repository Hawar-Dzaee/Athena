# HingeStdLoss

Part of [VICReg Loss Functions — Anatomy](/tutorials/regularization/vicreg-losses).

**Goal:** ensure each feature dimension maintains at least a minimum standard
deviation across the batch. If std drops below a margin $\gamma$, a hinge
penalty kicks in. This prevents **point collapse** — the failure mode where
all representations converge to a single constant.

```python
class HingeStdLoss(torch.nn.Module):
    def __init__(self, std_margin: float = 1.0):
        super().__init__()
        self.std_margin = std_margin

    def forward(self, x: torch.Tensor):
        x = x - x.mean(dim=0, keepdim=True)
        std = torch.sqrt(x.var(dim=0) + 0.0001)
        std_loss = torch.mean(F.relu(self.std_margin - std))
        return std_loss
```

**Line by line:**

- `x.var(dim=0)` — variance of each feature across the batch (Bessel-corrected, divides by $N-1$).
- `+ 0.0001` — numerical guard to avoid $\sqrt{0}$.
- `F.relu(self.std_margin - std)` — the hinge: zero when $\text{std} \geq \gamma$,
  positive penalty when below.
- `torch.mean(...)` — average the per-feature penalties into one scalar.

**Input data:** the heatmap below shows the raw $N \times D$ data matrix.
Blue is negative, red is positive, dark is near zero. Switch between three
datasets to see when HingeStdLoss fires — and when it *doesn't* even though
something is wrong:

- **Ideal** — messy random data, high per-dim std, loss is zero.
- **Collapsed** — all samples are nearly identical, std ≪ γ, maximum penalty.
- **Dim. Collapse** — samples differ (std is fine), but every dimension
  carries the same value per sample. HingeStdLoss reads 0 — only
  CovarianceLoss can catch this.
